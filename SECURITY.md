# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in `storedoc-rust` (such as credential leakage, HMAC bypass, TLS/redirect issues, or path traversal), please report it privately via:

- GitHub Security Advisories: https://github.com/storedoc/storedoc-rust/security/advisories/new
- Email: hinditutorpoint@gmail.com

Please include:
1. A description of the vulnerability and its potential impact.
2. Steps or a minimal reproduction to demonstrate the issue.
3. Any suggested fix, if available.

We will acknowledge receipt within 48 hours and coordinate a fix before public disclosure.
